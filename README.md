# Personal research website

A static site: plain HTML, CSS and JS, with no build step for the pages. Everything in `site/` is what gets uploaded.

```
site/
  index.html          homepage: bio, research map, active projects, latest papers
  projects.html       all projects        (reads site/data/projects.json)
  publications.html   all publications    (reads site/data/map.json)
  data/map.json       generated by scripts/build_map.py, do not edit by hand
  data/projects.json  edit by hand
  imgs/profile.jpg    add your photo here
data/
  publications.json   master list of my outputs (edit by hand)
  cache/              OpenAlex downloads + embeddings (safe to delete)
scripts/build_map.py  builds the research map
```

## Adding a publication

1. Add an entry to `data/publications.json`. Give it a new `id` and the `year`, `kind`, `title`, `authors`, `venue` and `doi` (or `null`). Allowed `kind` values: article, conference, abstract, talk, thesis, report, course, data, other.
   If the title is not in English, or is very short, add a `"text"` field with an English description. Only the map uses it.
2. Rebuild the map. Only new items get embedded, so it takes about a minute:

   ```powershell
   & "$env:USERPROFILE\.venvs\paper-map\Scripts\python.exe" scripts\build_map.py
   ```

   (The Python environment lives in your user folder rather than in Dropbox, so the ~1 GB of PyTorch doesn't sync.)

## Previewing locally

The pages load JSON, so they need a small web server rather than a double-clicked file:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m http.server 8765 --directory site
```

Then open http://localhost:8765.

## Publishing

The site is live at https://lenkica.github.io (repository `lenkica/lenkica.github.io`). Every push to `main` republishes the `site/` folder through `.github/workflows/pages.yml`; it takes about a minute. After editing:

```powershell
git add -A
git commit -m "Describe the change"
git push
```

(If `git` is not found in an older terminal, open a new one, or use `& "C:\Program Files\Git\cmd\git.exe"`.)

## How the map is made

- Background: ~1,500 English-language articles (2012–2026) from each of three fields, sampled from OpenAlex with a fixed seed:
  - Cell Biology + Cellular & Molecular Neuroscience
  - the Data Visualization and Analytics topic
  - Artificial Intelligence
- Every paper (title + abstract; title or `text` only where no abstract exists) is embedded with `BAAI/bge-small-en-v1.5`.
- UMAP (cosine, 30 neighbours) gives the 2D layout. A separate 10-D UMAP + HDBSCAN finds topic clusters, labelled by their most distinctive words (c-TF-IDF).
- The dashed line joins the average position of my work in each year.
